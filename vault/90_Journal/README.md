# 90_Journal

Date-prefixed session entries: `YYYY-MM-DD-topic.md`, or
`YYYY-MM-DD-project-topic.md`.

Use `scripts/scaffold_journal.py` so the filename and frontmatter cannot drift.

The journal is what actually happened. The project home note is what is currently true.
When they disagree, the journal is usually right about the past and the project note is
usually right about the present -- and the disagreement itself is worth a look.
